📌 Project Overview

AtomQuest Goal Portal is a role-based performance management system designed to streamline employee goal setting, manager approvals, and organization-wide performance tracking.

The platform provides:

Employee goal management
Quarterly progress tracking
Manager approval workflows
Admin analytics dashboards
AI-assisted SMART goal generation
Enterprise-grade analytics UI

This project was developed as a hackathon MVP focused on:

modern UX
rapid workflow management
scalable dashboard architecture
AI-assisted productivity
